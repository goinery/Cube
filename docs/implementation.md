# 实现与验证记录

## 架构

- React 19 + Three.js + TypeScript + Vite 静态应用；无需远端后端。
- `model.ts` 保存 8 角、12 棱、6 中心的身份、位置和方向。视图参数不写入物理状态。
- `store.ts` 统一历史、动画提交、播放器、编辑与计算锁定；拖拽预览只在完成吸附后提交合法动作。
- `Viewport.tsx` 分别构建角块、棱块、中心组件和核心；内部零件在装配状态始终保留。选择、贴图和辅助映射引用同一贴片身份。
- `interaction.ts` 处理松手吸附及实际投影边界的视图适配。
- `appearance.ts` 按共同图像区域切分贴片，记录裁剪边界；拆除组成员不会移动剩余片段。
- `preflight.ts` 用合法历史重建核对当前状态，并建议是否需要颜色或图片方向还原。
- `solver.worker.ts` 在 Worker 内求解；取消会真正终止该 Worker，过期消息不再更新界面。计算超时 60 秒自动停止，可重试。
- `persistence.ts` 用 IndexedDB 保存本地方案；导入校验合法历史、状态校验串、图片格式、片段归属和参数范围。
- `webmcp.ts` 在浏览器支持时注册 `read_cube_state` 和 `play_cube_algorithm`，使用相同的状态和播放器。当前环境无支持的 WebMCP 验证上下文，未验证浏览器注册；仅测试共享动作和错误处理。

## 本轮用户反馈

1. 相机近裁剪 0.005、最小轨道距离 0.08；适配实际模型投影至可用视图 75%，双击部件适配至 90%。
2. 按住实时拖层，松手按最近的整层角度及有限释放速度吸附；取消拖拽回原位，状态只在动画完成时写入。
3. 隐藏面从独立屏幕卡片改为场景内的平移辅助面，跟随观察方向定位并保持各面空间朝向。
4. 配置预检、计算建议、全局计算锁定、Worker 终止和成功自动播放。
5. 默认间距 0.006、贴片偏移 0.002；0.998 宽的圆角贴片接近拼合，并迁移旧默认间距。
6. 取消内部组件在零爆炸值的隐藏；补充空心支架、连接筋、轴套、弹簧垫圈和配对磁铁仓。

## 验证方式

- 自动检查 18 个标准面转与独立求解器状态一致；2,000 次随机转动及逆向复原。
- 三种求解模式均验证最终颜色及所有实体方向；CFOP 检查 Cross、F2L、OLL、PLL 各阶段结果。
- 检查撤销、重做、播放定位、暂停、快速连续输入、方案往返和非法输入拒绝。
- 检查磁力角度和释放速度、横竖屏及部件尺寸的 75% 投影适配、计算锁定和解除。
- 生产 Worker 使用实际构建文件执行；画布测试检查整面拼图、旋转和裁剪像素。
- 最终人工浏览器与触屏验收由用户进行；未声称经过制造级几何、刚体碰撞、工程公差或真实磁场验证。
