# 实现与验证记录

## 架构

- React 19 + Three.js + TypeScript + Vite 静态应用；无需远端后端。
- `model.ts` 保存 8 角、12 棱、6 中心的身份、位置和方向。视图参数不写入物理状态。
- `store.ts` 统一历史、动画提交、播放器、编辑与计算锁定；拖拽预览只在完成吸附后提交合法动作。
- `Viewport.tsx` 分别构建角块、棱块、中心组件和核心；内部零件在装配状态始终保留。选择、贴图和辅助映射引用同一贴片身份。
- `interaction.ts` 处理可调强度/阻尼的归位弹簧、未对齐层的冲突检查与整体旋转坐标变换，以及实际投影边界的视图适配。
- `geometry.ts` 提供角块、棱块及中心块的差异化贴片轮廓；`projection.ts` 从每个贴片的实时世界矩阵生成辅助面，覆盖中间转角与拆解。辅助面使用独立深度绘制，底面不受地面阴影遮挡。
- `mechanics.ts` 构建角块三面内壳、边块鞍形内壳、嵌入式磁铁仓、空心连接颈和独立防脱脚。角块使用带六角孔的三角碟形卡脚，边块使用带轴套和防脱槽的双翼导向脚；黑色内壳配有程序化蜂窝浅纹，彩色卡扣随贴片颜色更新。
- `camera.ts` 以四元数旋转完整观察坐标系，允许连续越过上下极点和滚转；视角切换分别插值朝向与距离，避免从相反面切换时穿过模型。
- `studio.ts` 提供棚拍反射环境及可平铺、带多级渐远过滤的微表面纹理。倒角共享平滑法线，颜色面与收边有细微明暗差异；方向光的阴影范围和地面高度跟随真实贴片边界。
- `appearance.ts` 按共同图像区域切分贴片，记录裁剪边界；拆除组成员不会移动剩余片段。
- `preflight.ts` 用合法历史重建核对当前状态，并建议是否需要颜色或图片方向还原。
- `solver.worker.ts` 在 Worker 内求解；取消会真正终止该 Worker，过期消息不再更新界面。计算超时 60 秒自动停止，可重试。Vite 将 `cubejs` 别名解析到本地保留源码，并显式预构建两种 CommonJS 求解依赖，确保开发环境的模块 Worker 也能加载。
- `persistence.ts` 用 IndexedDB 保存本地方案；导入校验合法历史、状态校验串、图片格式、片段归属和参数范围。
- `webmcp.ts` 在浏览器支持时注册 `read_cube_state` 和 `play_cube_algorithm`，使用相同的状态和播放器。当前环境无支持的 WebMCP 验证上下文，未验证浏览器注册；仅测试共享动作和错误处理。

## 本轮用户反馈

1. 相机近裁剪 0.005、最小轨道距离 0.08；适配实际模型投影至可用视图 75%，双击部件适配至 90%。
2. 按住实时拖层，松手按最近的整层角度及有限释放速度吸附；取消拖拽回原位，状态只在动画完成时写入。
3. 隐藏面从独立屏幕卡片改为场景内的平移辅助面，跟随观察方向定位并保持各面空间朝向。
4. 配置预检、计算建议、全局计算锁定、Worker 终止和成功自动播放。
5. 默认间距 0.006、贴片偏移 0.002；0.998 宽的圆角贴片接近拼合，并迁移旧默认间距。
6. 取消内部组件在零爆炸值的隐藏；补充空心支架、连接筋、轴套、弹簧垫圈和配对磁铁仓。

## 2026-09-10 实物参考图调整

- 按 `调整初始缩放和角度.webp` 设置对称三分之四视角：水平 45°、仰角约 24.7°、视场角 30°，默认占用限制视口尺寸的 68%。标准产品视角与初始视角一致；“适配视图”仍使用 75%，部件特写使用 90%。
- 按角块、边块及其邻面照片重做内壳和导向脚。使用原创几何表达照片中的装配特征，48 颗角边磁铁一一对齐，保留 16 颗核心相关磁铁及现有六轴中心结构。装配、分块与内部拆解共用同一批零件。
- 默认光源固定在世界坐标中，位置不随相机、转层或拆解改变；仅阴影覆盖范围跟随模型尺寸。视角面板可调整光源方向（−180°～180°）、仰角（−80°～80°）、强度（0～5），并可开启跟随视角。反射环境和补光与主光源朝向同步。
- 鼠标拖动空白或在视角/拆解模式拖动可自由旋转；右键拖动也可旋转，Shift 拖动可滚转；双指平移旋转、开合缩放、扭转滚转。操作只改变观察视角，不改变魔方状态。
- 新增灯光参数随方案保存，旧方案自动使用固定光源默认值。
- `verify-visual.ts` 已接入 `npm run verify`，检查连续 720° 翻转、滚转、复合旋转、缩放、相反面视角切换、横竖屏初始构图、灯光独立性、方案兼容、磁铁配对和导向脚通孔。构建、完整回归与本次改动文件的 lint 均通过；浏览器实际检查了装配/分块/结构展开、跨极点连续旋转和灯光方向滑块。真实多点触屏仍需设备验收。
- 参数条使用边对齐滑块，位置在挂载时测量一次。手机与横屏面板初始为 `display:none`，此时测不到轨道宽度，填充条与滑块会一直隐藏；`Range` 现在在容器重新可见时重挂载滑块，重新测量后再显示。

## 验证方式

- 自动检查 18 个标准面转与独立求解器状态一致；2,000 次随机转动及逆向复原。
- 三种求解模式均验证最终颜色及所有实体方向；CFOP 检查 Cross、F2L、OLL、PLL 各阶段结果。
- 检查撤销、重做、播放定位、暂停、快速连续输入、方案往返和非法输入拒绝。
- 检查磁力角度和释放速度、横竖屏及部件尺寸的 75% 投影适配、计算锁定和解除。
- 生产 Worker 使用实际构建文件执行；开发 Worker 回归测试通过隔离 Vite 服务获取真实 ESM 模块，在无 CommonJS 全局变量的环境中执行三种模式并验证还原结果。画布测试检查整面拼图、旋转和裁剪像素。
- 最终人工浏览器与触屏验收由用户进行；未声称经过制造级几何、刚体碰撞、工程公差或真实磁场验证。
