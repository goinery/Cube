# 性能优化记录

此次优化保留模型几何、圆角、贴图尺寸、材质、像素比、阴影分辨率和磁力/动画参数。

- 3D 视图按需请求动画帧。静止时停止，操作、图片就绪、窗口尺寸变化和回到页面时唤醒；自动旋转、转层、拆解与视角过渡期间持续更新。渐进动画收敛至原目标值后停止。
- 固定机械细节复用局部矩阵，零件布局和包围盒仅在形状变化时更新。阴影仅在零件姿态、灯光方向或阴影尺寸变化时重新生成。
- React 组件订阅各自使用的状态，投影标签变化不再重绘整个控制面板。定制、求解和六面网格使用组件缓存。
- 只重绘外观实际变化的贴片，已有图片纹理复用 GPU 资源；普通纯色贴片直接使用材质颜色。同一图片的并发加载共享解码 Promise，图片缓存最多保留 64 项，失败可重试。
- 自动保存直接比较持久化字段，避免在投影更新时反复序列化参数，同时覆盖操作历史分支和打乱信息变化。
- Tailwind 仅扫描工作室及当前使用的 select、slider、switch 组件。以后引入其他 UI 组件时，应在 `web/app/globals.css` 添加相应 `@source`。

## 已记录的结果

本机 Edge 无头浏览器，1440 × 1000、像素比 1、默认画质。每种状态采样 1.2 秒；绘制调用统计来自 WebGL 接口，不能换算为其他设备的帧率或耗电比例。

| 状态 | 优化前绘制调用 | 优化后绘制调用 |
| --- | ---: | ---: |
| 默认静止 | 315,948 | 0 |
| 完全拆解后静止 | 275,268 | 0 |
| 无磁力错位停留 | 274,968 | 0 |
| 磁力归位结束 | 317,304 | 0 |

自动旋转可以重新唤醒并持续绘制。默认、拆解和错位三组截图在像素比较阈值 0.1 下未检出差异。截图比较先于最后的样式扫描范围调整。

构建 CSS 从 209.92 KB 降为 59.90 KB（减少约 71.5%）；gzip 从 34.21 KB 降为 13.03 KB（减少约 61.9%）。JavaScript 因缓存和调度逻辑增加约 3.8 KB，gzip 增加约 1.3 KB。

已完成 TypeScript/生产构建和现有 `verify` 流程（状态、求解、历史、图片方向、磁力、投影、结构及开发 Worker）。收到用户自行测试的指示后，未继续测试或构建。

## 可复用的浏览器采样

`web/scripts/verify-performance-browser.mjs` 使用隔离的浏览器上下文，不读取现有浏览器方案。需要 Playwright 和 Microsoft Edge，可用 `AXIS_PLAYWRIGHT_MODULE` 指定已有 Playwright 的模块路径，不要求新增项目依赖。

在 `web` 目录运行脚本。`AXIS_PERF_URL` 默认为 `http://127.0.0.1:3017/`，需指向 Vite 开发服务；`AXIS_PERF_OUTPUT` 指定截图和计数的输出目录，默认 `.performance/current`。设置 `AXIS_PERF_ASSERT=1` 会检查静止绘制为零。`.performance` 已排除在 Git 之外。
