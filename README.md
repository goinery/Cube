# AXIS / 03 魔方工作室

在浏览器中玩、拆解、定制和还原真实状态的 3×3×3 磁力魔方。所有图片、方案和求解均在本机处理。

## 运行

已安装依赖时，在项目根目录运行 `npm run dev`，打开 http://localhost:3000/。Windows 也可以双击 `start.bat`。

新环境需要 Node.js 22.13 或更新版本，然后在根目录运行 `npm run setup`。当前电脑的启动脚本会自动使用已安装的兼容运行时。

`npm run build` 生成 `web/dist/`。运行 `npm start` 可预览构建结果；部署时将该目录放到静态 HTTP 服务中即可。不要直接双击 HTML，浏览器需要通过 HTTP 加载模块和求解 Worker。

## 操作

- 在「玩魔方」中按住贴片拖动，层转角度实时跟手。「磁力与手感」可调磁力强度（0–2）和归位阻尼（0.05–2）：开启磁力时根据角度和释放速度吸附到 90° 倍数，低阻尼有明显回弹，高阻尼缓慢归位。
- 磁力强度为 0 时，松手停留在任意角度；再次拖动会从当前位置继续。同轴各层可独立转动，整体旋转会携带错位姿态。重新开启磁力后各错位层依次归位；磁力归位中将磁力调为 0 也会立即停留。
- 「玩魔方 → 磁力与手感 → 转层容错角度」支持 0–45° 调节，默认 10°。尝试垂直转层时，若各错位层到最近 90° 位置的偏差都在范围内，会先用约 160–230 毫秒的平滑动画就近归位，再执行新转动；时长随播放速度调整，磁力为 0 时也有效。拖拽会等待归位并保留最新指针位置，归位期间松手则取消待执行的拖拽。超出范围时保持原姿态；0° 恢复严格对齐。参数随方案保存，按钮、键盘、拖拽、算法和撤销重做使用相同规则。
- 拖动空白处或使用右键自由旋转视角，可连续上下翻转，无极点限制；Shift 拖动滚转，滚轮缩放。触屏双指平移旋转、开合缩放、扭转滚转。在「视角」「拆解」中拖动部件也会旋转视角。
- 初始视角按参考图设置为水平 45°、仰角约 24.7°的产品视角，模型占限制画面尺寸约 68%。「适配视图」使用 75%；双击任一可见部件可进入特写，用「适配视图」返回全貌。
- 默认键盘 R/L/U/D/F/B 转层，Shift 反向，Alt 半圈；空格播放或暂停，Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。「面转动 → 自定义操作键位」可分别修改各面的正转、反转、半转，以及撤销、重做、播放暂停和退出展示键位；点击输入框后按下单键或组合键，Delete / Backspace 清除，Esc 取消，支持冲突提示和恢复默认。键位随方案自动保存、导入导出，旧方案使用默认值。
- 「算法实验室」内通过按钮切换算法，默认只有「大中小魔方」（`F D2 L2 B D B' F2 U' F U F2 U2 F' L D F' U`）和「大小魔方」（`U2 L2 F2 U' B2 D R F' R F' R F' D' B2 U'`）。点击按钮在输入框显示公式，再点击「播放算法」从当前状态执行。「添加」可命名并保存新的算法按钮，支持独立 JSON 导出、导入；导入合并到现有列表，重复公式跳过，同名的不同公式自动加序号。算法列表也随方案自动保存和导入导出。算法还支持 M/E/S、宽层和 x/y/z 整体转动。
- 「隐藏面映射」逐片复制真实贴片的位置、朝向和形状，随转层、任意角度停留及拆解实时变形；从侧面转入的贴片也会进入映射。辅助面与对应面成镜像关系：主视图里位于魔方左侧的贴片，映射里也在左侧，因此顺时针转顶层时隐藏面映射呈现相反的转动方向。辅助面独立绘制并置于魔方之后，底面映射不会被地面阴影遮挡，主视图的魔方也不会被投影面挡住。还可切换六面总览和平面展开。
- 「拆解」连续调整外部拆分及内部零件分离。爆炸值为 0 时内部结构仍存在，通过正常遮挡呈现装配状态。
- 「定制」可多选贴片、整面拼图、上传六面照片。上传或替换图片先打开整面效果预览，可直接拖动定位、调整缩放、旋转、适配和裁切，确认应用后更新贴片，取消保留原外观；已应用图片可通过「打开预览调整」继续编辑。配色提供原厂、霓虹和撞色，后两套使用区分明显的六种颜色。在 3D 视图中单击空白处即可取消当前选择。支持本地自动保存、手动保存及 JSON 导入导出。
- 「求解」点击「开始求解」即开始计算，完成后自动播放，支持暂停、逐步回看和 CFOP 阶段跳转。序列播放器位于「求解」区块内，只在需要播放时随该区块出现，不再常驻面板底部；打乱动画、算法播放和历史回放同样在其中控制。计算时魔方及编辑操作锁定，可点击进度旁的「终止」；只有配置不合法、已经复原或需要开启图片方向还原时，才会给出说明。
- 「检查」回放操作历史时会从复原态逐步重现当前历史，按钮同时变为「终止回放 · 已回放步数 / 总步数」，随时点按即可停在当前步骤；终止后已应用的转动保留在历史中，可继续撤销或从当前位置继续操作。
- 手机端控制面板默认收起，只保留小横条把手与六个菜单项，3D 魔方占满其余屏幕。按住小横条拖动即可连续调整面板高度：向上拖展开到任意高度，向下拖到底自动吸附回收起态，拖到上限时会为 3D 视图留出最小空间；轻点小横条在收起与上次高度之间切换，点按任一菜单项会展开并跳到对应区块。横屏手机把面板放在右侧，拖动方向改为左右，收起时压缩成窄条。

默认间距为 0.006，贴片偏移为 0.002；可在拆解面板进一步调节。圆角及真实转层所需的细缝仍保留。

贴片按参考图建模：角块为小圆角方形，棱块朝向面中心的一侧使用大圆角，中心块四角均为大圆角；3D 模型、辅助投影及平面格子采用对应轮廓。磁力参数和未对齐角度会随方案一起保存，旧方案自动使用默认磁力参数。所有参数条都支持手动输入：回车或失焦提交，非数字会提示并回退原值，超出范围会按界限取值。

外壳采用索引圆角曲面、轻微拱面及连续法线，配合低强度清漆反射与细微注塑纹理。棚拍光源压低曝光，以右侧补光保留颜色和边缘高光；内部塑料、导轨与金属磁铁有独立材质。深色底衬减少块缝漏亮，接触阴影使用一次生成的渐变纹理。实时阴影按外形收紧范围，地面随最低部件调整，低画质会降低阴影分辨率。在「视角」中可继续调节塑料粗糙度与显示品质；「进入展示模式」会隐藏面板并自动开启旋转，点击空白处暂停或继续自动旋转，拖动和双指手势保持视角操作。退出时恢复进入前的旋转设置。

角块与边块按 docs 内实物照片优化：黑色蜂窝内壳、嵌入式磁铁仓、彩色卡扣和空心连接颈；角块采用乳白色三角碟形卡脚，边块采用乳白色双翼导向脚与防脱槽。光源默认跟随视角，可在「视角 → 棚拍光源」关闭跟随并调整方向、仰角和强度；灯光设置随本地方案保存，旧方案同样以跟随视角开启载入。

## 验证

`npm run verify` 检查合法转层、状态和方向一致性、三种求解器、CFOP 阶段、撤销重做、方案导入导出、磁力吸附、75% 视图适配和计算期间的操作锁定。另包含参考轮廓射线检测、逐片投影矩阵、不同帧率/强度/阻尼的弹簧稳定性、任意角度姿态连续性、错位冲突限制、整体旋转后的错位轴变换及方案兼容性验证。

构建后可在 `web` 中运行 `npx tsx scripts/verify-worker.ts`，验证生产 Worker 的 Fast、Near-optimal、CFOP 三种结果。`verify-art.ts` 是可选的画布像素测试，需要 `@napi-rs/canvas`，可用 `AXIS_CANVAS_MODULE` 指定其路径。

常规验证还会启动隔离的 Vite 开发服务，在不提供 Node.js `require`/`module` 全局变量的 ESM 环境中加载实际 Worker 模块，检查三种求解模式的颜色与图片还原，防止出现生产构建通过、开发页面却无法启动求解器的情况。

3D 绘制按需唤醒：静止后停止绘制，拖动、转层、容错归位、拆解过渡与自动旋转期间保持连续更新，页面隐藏时暂停。相同机械几何合并为实例批次，完整包围盒被外壳遮挡或位于视野之外的部件不提交主视图绘制；拆解和错位露出的部件自动恢复。阴影使用独立实例缓冲，避免相机背面的部件被省略后丢失投影。未变化的矩阵、阴影及贴图会复用。优化记录见 [docs/performance.md](docs/performance.md)。

已完成编译、自动逻辑验证及默认/拆解/错位视图的浏览器截图对比。不同设备的视觉比例、拖拽手感和人工触屏体验仍需在目标设备验收。

## 实现范围

26 个独立零件保存整数坐标及精确方向基；核心、6 根轴杆、中心空心轴套、弹簧、垫圈、调节盘、角棱支架、卡脚及磁铁仓分别建模。模型采用真实魔方的结构关系和合法转层运动；磁力吸附采用交互动画模型，未进行工程制造公差或刚体碰撞仿真。

Fast 使用两阶段搜索；Near-optimal 比较多个搜索起点，不保证数学最短解；CFOP 使用 Cross/F2L/OLL/PLL，图片中心方向通过合法转层补充校正。没有通过反放历史伪造求解，也不会直接重写单块方向来还原图片。

源代码位于 `web/components/cube` 与 `web/lib/cube`，验收需求保留在 `docs/demand.md`。第三方求解器及许可见 `docs/implementation.md`。
